# PROMPT PEMBUATAN MOBILE APP — NASJAK APP

Buat sebuah mobile application modern bernama “NASJAK APP” (Nasuha Jakarta App) sebagai platform digital resmi komunitas NASUHA Jakarta, yang menjadi pusat informasi, edukasi, ibadah, motivasi, komunitas, dan kegiatan dakwah bagi Sahabat NASUHA.

## 1. KONSEP UTAMA

Nama aplikasi:
NASJAK APP

Subjudul:
“Teman Hijrah, Teman Berproses, Teman Bebas Utang”

Tujuan aplikasi:

* Menjadi pusat digital komunitas NASUHA Jakarta.
* Membantu Sahabat NASUHA meningkatkan kualitas ibadah.
* Menyediakan akses Al-Qur’an dan Hadis.
* Menyediakan checklist ibadah/riyadhoh pribadi.
* Memberikan motivasi dan edukasi seputar hijrah dan bebas utang.
* Menampilkan testimoni Sahabat NASUHA yang telah menyelesaikan utang.
* Menampilkan event NASUHA.
* Menghubungkan pengguna dengan media sosial resmi NASUHA Jakarta.
* Memudahkan pengguna mendapatkan informasi Temu Solusi Nasuha (TSN) dan Langkah Bebas Utang (LBU).

Desain harus terasa:
Islamic • Modern • Clean • Professional • Warm • Inspirational • Community-driven • Trustworthy

## APS Bridge API — Summary

**Project structure** (`aps_bridge/`): 14 new files created alongside the existing Three.js viewer.

### API Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| `POST` | `/api/v1/models/upload` | Upload .rvt file to APS bucket + start SVF2/IFC translation |
| `GET` | `/api/v1/models` | List all uploaded models |
| `GET` | `/api/v1/models/{id}/status` | Poll translation progress from APS manifest |
| `GET` | `/api/v1/models/{id}/download-ifc` | Get IFC download URL |
| `POST` | `/api/v1/models/{id}/extract-metadata` | Extract BIM properties via Model Derivative API, MERGE into BIM_ELEMENTS |
| `GET` | `/api/v1/models/{id}/element-status` | Asset health/risk per BIM element (feeds viewer overlay) |
| `POST` | `/api/v1/sync/refresh-scores` | Refresh ASSET_HEALTH_SCORE + MAINTENANCE_RISK from views |
| `GET` | `/viewer/{id}` | 3D viewer page with Autodesk Viewer 7.x |
